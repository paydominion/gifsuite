# Satoshi

Satoshi by Indian Type Foundry, from Fontshare (https://www.fontshare.com/fonts/satoshi). Licensed under the ITF Free Font License. The full text is in `FFL.txt`.

Files: `Satoshi-Variable.woff2` and `Satoshi-VariableItalic.woff2` (variable weights 300–900), byte-identical to Fontshare's official download.

## What the license means for GifSuite

- **Allowed:** self-hosting it for GifSuite's own website UI (§01).
- **Don't modify the files.** No subsetting, format conversion or renaming (§02). `next/font/local` serves them as-is; keep it that way.
- **Don't offer it to users as a font for their own content** (§02). The planned "Text captions" tool must use a different, openly licensed font (e.g. an SIL OFL font) for the text users add to GIFs.
- **Don't put these files in a public repository** (§02, distribution through publicly accessible servers). Keep the GitHub repo private, or exclude `app/fonts/*.woff2` if it's ever made public.
