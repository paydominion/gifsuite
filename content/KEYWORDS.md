# Keyword research

Monthly searches in the US from the Keywords Everywhere API (Google Keyword Planner data), checked 2026-10-15. Refresh with `npm run keywords -- --topics` or `npm run keywords -- "keyword" …`.

## The big finding: tool pages beat blog posts

Searches for doing a task are 100–1,000× bigger than searches about GIF history. The tools GifSuite already has match several of them, but no page is aimed at those searches yet. Dedicated landing pages (one keyword, one page, the tool on it) are the biggest SEO lever.
